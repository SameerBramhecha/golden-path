# Security Policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues.

Use GitHub's **Report a vulnerability** feature on this repository's Security tab to submit a private report. Include the affected version or commit, impact, reproduction steps, and any safe proof of concept.

## Scope

Golden Path will handle credentials, invoke local tools, build container images, and may eventually provision cloud infrastructure. Reports involving credential exposure, command execution, unsafe generated artifacts, privilege boundaries, or accidental infrastructure deletion are particularly important.

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure.
